# Nossa Casa - Deploy Vercel

## 🚀 Deploy em 60 Segundos

### Passo 1: Abra Vercel
https://vercel.com/new

### Passo 2: Importe o Repositório
1. Clique "Continue with GitHub"
2. Procure: `nossa-casa`
3. Clique "Import"

### Passo 3: Configure (Padrões OK)
- Project Name: `nossa-casa`
- Framework: `Other` (deixe em branco)
- Build Command: `npm run build` (deixe vazio)
- Output Directory: `dist`
- Environment: (deixe vazio)

### Passo 4: Deploy
1. Clique "Deploy"
2. Aguarde 30-60 segundos

### ✅ App Estará Live Em:
```
https://nossa-casa.vercel.app
```
