# GitHub Pages - Configuração

## 🔧 CONFIGURAÇÃO AUTOMÁTICA

### Para ativar GitHub Pages no seu repositório:

1. **Abra**: https://github.com/antoniomadeira76/nossa-casa/settings/pages

2. **Em "Build and deployment":**
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

3. **Clique "Save"**

4. **Aguarde 2-3 minutos**

5. **Acesse**: https://antoniomadeira76.github.io/nossa-casa
