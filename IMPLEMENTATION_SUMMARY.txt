3. ESTRUTURA DE EVENTOS IMPORTADOS
================================================================================

Input (Google Calendar):
{
  id: "gcal-1",
  title: "Reunião de equipa",
  date: "d2026-08-28",          // formato interno: d{y}-{m}-{d}
  time: "14:00",                // HH:MM
  description: "...",           // opcional
  isRecurring: false            // flag de recorrência
}

Output (Armazenado em "added"):
{
  id: "gcal-{timestamp}-{random}",  // ID único, não colide
  day: "d2026-08-28",               // chave ordenável
  time: "14:00",
  title: "Reunião de equipa",
  who: "Rita",                      // quem adicionou
  owner: "Rita",                    // proprietário
  shared: true,                     // família (true) ou privado (false)
  source: "Google Calendar",        // tag de origem
  isRecurring: false,               // preservado do original
}

Rastreamento (googleCalendarImported):
{
  "gcal-1": true,
  "gcal-2": true,
  "gcal-3": true,
  // ... IDs de eventos já importados
}

================================================================================
4. FLUXO DE UTILIZAÇÃO
================================================================================

1. LOGIN
   → Utilizador faz login (Rita ou Tomás)
   → Não é uma criança (verifica MEMBERS[user].kid)

2. PRIMEIRA IMPORTAÇÃO
   → useEffect detecta googleCalendarImported vazio
   → Modal aparece automaticamente com 3 mock events

3. SELECÇÃO
   → Utilizador pode ativar toggle "Incluir eventos recorrentes"
   → Seleciona eventos a importar (recorrentes opcionais)

4. IMPORTAÇÃO
   → Clica "Adicionar" (família) ou "Só para Mim" (privado)
   → importGoogleEvents() processa eventos
   → Eventos adicionados à lista "added"
   → IDs marcados em googleCalendarImported
   → Modal fecha

5. IGNORAR
   → Clica "Ignorar"
   → IDs marcados em googleCalendarImported
   → Modal não aparece novamente para esses eventos

6. VISUALIZAÇÃO
   → Eventos aparecem na Agenda
   → Visibilidade respeitada (privado vs. família)
   → Source "Google Calendar" identifica origem
