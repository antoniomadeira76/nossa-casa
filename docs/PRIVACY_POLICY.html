Política de Privacidade

Nossa Casa — Aplicação de Gestão Familiar

Última atualização: 26 de agosto de 2026
Versão 1.0

1. Introdução

A Nossa Casa ("Aplicação") é uma aplicação de gestão familiar que ajuda as famílias a organizar agenda, tarefas, compras, finanças e registos de saúde.

Esta Política de Privacidade explica como recolhemos, utilizamos e protegemos os seus dados pessoais quando utiliza a Nossa Casa.

2. Responsável pelo Tratamento de Dados

Nome: Nossa Casa — Gestão Familiar

Email: privacy@nossacasa.app

Endereço: Lisboa, Portugal

3. Dados que Recolhemos

3.1 Dados de Autenticação

  • Nome
  • Email
  • Foto de perfil (opcional)
  • Google Account ID (se autenticação via Google)

3.2 Dados de Conteúdo

  • Eventos de calendário (criados ou importados)
  • Tarefas e listas de afazeres
  • Listas de compras
  • Registo financeiro (orçamentos, despesas, envelopes)
  • Informações de equipamentos domésticos
  • Registos de saúde (consultas, exames, receitas)
  • Notas e documentos

3.3 Dados Técnicos

  • Tipo de dispositivo e sistema operativo
  • Endereço IP
  • Timestamps de acesso
  • Erros e falhas da aplicação (para melhorias)
⚠️ Dados Especiais (Saúde):
Registos de saúde são dados pessoais sensíveis conforme a lei de proteção de dados. Apenas membros adultos da família podem aceder aos seus próprios registos, e aos dos menores. Nunca partilhamos estes dados com terceiros.

4. Base Legal para Processamento

Processamos os seus dados com base em:

  • Consentimento: Ao utilizar a aplicação, consente no processamento dos seus dados
  • Contrato: Necessário para fornecer os serviços da aplicação
  • Obrigação Legal: Conformidade com RGPD e leis de proteção de menores

5. Como Utilizamos os Seus Dados

  • Fornecer os serviços da aplicação
  • Sincronizar dados entre dispositivos (se ativado)
  • Melhorar a aplicação e experiência do utilizador
  • Cumprir obrigações legais
  • Responder a pedidos de suporte
  • Enviar notificações relacionadas com agenda e tarefas

6. Partilha de Dados

Não partilhamos os seus dados com terceiros exceto:

  • Google: Se utiliza autenticação via Google (apenas ID + email)
  • Supabase: Se sincronização online está ativada (dados encriptados)
  • Autoridades: Se obrigados por lei

Dentro da sua família: Dados são partilhados apenas entre membros da família conforme as permissões que define (e.g., eventos partilhados, tarefas atribuídas).

7. Segurança dos Dados

  • Encriptação de dados em trânsito (HTTPS)
  • Armazenamento local encriptado (dispositivo)
  • Sincronização online com encriptação end-to-end (se ativada)
  • Sem acesso administrativo aos dados pessoais
  • Conformidade com OWASP Top 10

8. Direitos do Utilizador (RGPD)

Tem o direito de:

  • Acesso: Ver todos os dados que temos sobre si
  • Retificação: Corrigir dados incorretos
  • Eliminação: Apagar a sua conta e todos os dados ("direito ao esquecimento")
  • Portabilidade: Receber os seus dados num formato legível
  • Oposição: Recusar certos processamentos

Para exercer estes direitos, contacte: privacy@nossacasa.app

9. Retenção de Dados

  • Dados ativos: Mantidos enquanto utiliza a aplicação
  • Após eliminação de conta: Apagados permanentemente em 30 dias
  • Backups: Mantidos por 90 dias (depois apagados)
  • Logs técnicos: Apagados após 30 dias

10. Proteção de Menores

A aplicação é destinada a famílias com menores. Protegemos as crianças através de:

  • Interface específica para modo criança (sem acesso a dados financeiros)
  • Controlo parental (PIN obrigatório)
  • Sem publicidade direcionada
  • Sem rastreamento online
  • Dados de menores não são partilhados sem consentimento dos encarregados

11. Cookies e Rastreamento

A aplicação móvel não utiliza cookies. A versão web utiliza:

  • Cookies essenciais: Autenticação e sessão
  • Cookies analíticos: Entender como utiliza a aplicação (opcional)
  • Rastreamento: Nenhum (sem Google Analytics, Facebook Pixel, etc.)

12. Alterações a Esta Política

Podemos atualizar esta política. Notificaremos por email de alterações significativas. Recomendamos que revise periodicamente.

13. Contactos

  • Privacidade: privacy@nossacasa.app
  • Suporte: support@nossacasa.app
  • Denúncia RGPD: dpd@nossacasa.app

14. Lei Aplicável

Esta política é regida pela lei portuguesa e pelo Regulamento Geral de Proteção de Dados (RGPD) da União Europeia.
